## 1. Engine Philosophy & Anti-Fabrication Mandate

Aarogya's prediction architecture adheres strictly to Rule 8 & 9 of the Master Specification:
> *Do not create fake AI predictions merely to make the system appear complete. If there is insufficient historical data for an ML model, implement a deterministic fallback prediction algorithm while keeping the FastAPI prediction-engine architecture ready for an actual ML model.*

Whenever a prediction is calculated, the system labels its true origin:
- `predictionSource: "AI"`: Generated by the trained Scikit-Learn regression model running in Python FastAPI using non-linear operational features.
- `predictionSource: "FALLBACK"`: Generated by the deterministic scheduling simulator when historical data is sparse or the FastAPI container is offline.

## 2. Dynamic Operational Factors

The wait time formula and ML feature vectors evaluate real-time clinic realities:

```
Total Wait = (Current Consultation Remaining Time)
           + (Patients Ahead * Effective Duration)
           + (Emergency Cases Ahead * Emergency Duration)
           + (Active Doctor Operational Delays)
```

### Factors Accounted For:
1. **Current Consultation Elapsed Duration:** If the current patient has spent 5 minutes in an 8-minute consultation, remaining time is 3 minutes. If the consultation has exceeded 8 minutes, an operational buffer (2 minutes) is estimated for completion.
2. **Recent Doctor Consultation Pace:** The rolling average of the doctor's last 5 completed consultations is compared against the standard departmental baseline. If the doctor is working 15% faster today, the effective duration adjusts dynamically.
3. **Emergency Disruption Weight:** Emergency cases are given high-priority insertion, factoring in their acute consultation window.
4. **Active Operational Delays:** Delays reported by the doctor (e.g. ICU rounds, ward emergency) are directly added to downstream calculations.
5. **Timezone Accuracy:** All consultation times are formatted in India Standard Time (`Asia/Kolkata`, UTC+05:30).
